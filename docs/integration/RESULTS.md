# 통합본 검증 결과

검증일 2026년 10월 19일

Flutter 파일 112개가 원본과 바이트 단위로 같고, 핵심 서버 모듈 7개가 기존 검증본과 같다. Flutter SDK가 이 세션의 실행 경로에 없어 앱 실행·빌드는 별도로 검사하지 않았다.

| demo | 42 | 0 | 0 | 224 | 224 |

기존 SQL 가져오기와 가상 샘플을 서로 다른 프로젝트·볼륨에서 실행했다. 두 환경에서 전체 계산 대비 추천 ID·순서·점수, 맛 수치 조합, 가격·카테고리·인식한 제외 조건, Qdrant 장애 503, API 키 없는 live 거절을 검사했다. 각 환경의 실제 HTTP 예시 네 개도 정상 반환했다.

초기화를 한 번 더 실행해 SQL 행 수와 Qdrant 포인트 수가 변하지 않음을 확인했다. 비밀번호·실제 SQL·수집 JSON을 Git이 포함할 목록에서 제외하는지 검사했고 알려진 OpenAI 키 패턴은 발견하지 않았다. 이것이 모든 비밀정보·저작권·개인정보를 보장하는 감사는 아니다.

이 테스트는 고정된 예시의 회귀 검사이며 새로운 독립 자연어 정확도나 전국 규모 성능 검증이 아니다. 이전 성능 수치는 docs/validated_experiments의 별도 실험 기록이다. 원본 프로젝트와 실험 폴더를 수정하거나 GitHub에 업로드하지 않았다.
