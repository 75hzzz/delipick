# 기존 구조를 유지한 통합 내용

이 문서는 최초 통합 방식의 설명입니다. 2026년 10월 25일 업로드 전 점검에서 설정 누락과 앱·초기화·배달 갱신 안전성 문제를 추가 수정했습니다. 최신 변경·검증 범위는 `release_audit/REPORT.md`를 따릅니다. 따라서 아래의 원본 그대로 복사했다는 설명은 최초 통합 시점을 뜻합니다.

기존 팀 프로젝트는 `delipick_app`과 `delipick_server`를 사용합니다. 이번 통합본은 이 구조를 유지하고 검증된 검색 변경과 Docker 실행 설정을 추가한 별도 복사본입니다. 원본 프로젝트, 기존 공유 데모, 성능 실험 폴더는 수정하지 않았습니다.

## 그대로 보존한 부분

Flutter 앱은 소스·자산·플랫폼 파일을 그대로 복사했습니다. 빌드 캐시와 로컬 SDK 경로만 제외했습니다. API 주소를 코드에서 바꾸지 않고 기존 `API_BASE_URL` 실행 옵션을 사용합니다. 원래 서버의 데이터·database·scripts 구성과 배달시간 로직도 보존했습니다. 원래 README는 별도 보관했습니다.

## 반영한 검색 코드

검증한 `main.py`, `recommendation_scoring.py`를 서버에 반영했고 `vector_search.py`, `candidate_recall.py`를 추가했습니다. `recommend_logic.py`, `recommendation_rules.py`, `update_delivery.py`는 검증본과 같은 파일입니다. 핵심 모듈 7개는 기존 Docker 검증 코드와 바이트 단위로 대조합니다.

조건을 먼저 분석하고 MySQL에서 후보를 줄인 뒤, 큰 후보 집합에는 Qdrant와 개인화 보완 채널을 적용합니다. 최종 점수는 기존 Python 점수식으로 계산합니다. 작은 후보 집합은 전체 계산합니다. 이것이 폴더 구조 변경 없이 반영한 검색 개선입니다.

## Docker에서만 추가한 부분

루트의 Dockerfile·Compose·환경 예시·시작 스크립트와 서버 내부 `deployment`를 추가했습니다. Docker용 어댑터가 자유 입력 또는 예시 재생 모드를 연결합니다. 기존 `python main.py` 실행 파일을 다른 위치로 옮기지 않았습니다.

첫 실행은 import 서비스가 기존 SQL을 빈 DB에 넣고, init 서비스가 태그 조회 테이블·인덱스와 Qdrant를 준비한 후 API가 시작되는 순서입니다. 이미 비어 있지 않은 DB에 SQL을 다시 적용하지 않습니다. 가상 샘플은 별도 프로젝트·볼륨으로 분리했습니다.

`requirements.txt`는 원래 패키지 목록을 유지하면서 UTF-16에서 UTF-8로 인코딩을 정리하고 qdrant-client를 추가했습니다. Docker는 기존 검증 환경에서 고정한 `requirements-docker.lock.txt`를 사용합니다. 로컬 requirements 설치 환경과 Docker 환경이 모든 하위 의존성까지 동일하다고 주장하지 않습니다. 기존 크롤러용 패키지와 스크립트는 유지하지만 Docker API 이미지가 브라우저 크롤러 실행 환경까지 제공하는 것은 아닙니다.

## 포함하지 않은 부분

성능 실험의 before·after 복사본, 가상환경, 로그 원시 자료, 원본 비밀키, Git 메타데이터와 슬라이드 미리보기는 합치지 않았습니다. 새 상황 태그 체계나 영업시간 하드 필터를 추가 구현한 것도 아닙니다. 기존 검증에서 미구현으로 표시한 항목은 그대로 미구현입니다.

원본 SQL과 수집 JSON은 이 PC의 로컬 작업을 위해 복사했지만 Git 공유 대상에서 제외했습니다. 따라서 SQL 파일을 제공하지 않은 새 GitHub 체크아웃에서는 실데이터 환경이 저절로 재현되지 않습니다. 팀원이 SQL을 따로 전달받는 기존 절차를 유지하거나, 별도 가상 샘플을 실행하면 됩니다.

## 검증 범위

이 통합본에서는 기존 SQL 가져오기, Qdrant 초기화, 두 실행 모드 분리, 전체 계산 대비 결과 재현, 조건 제외, Qdrant 장애 응답, 재기동을 검사합니다. 구체적인 결과는 `docs/integration`에 저장합니다. 이전 1·10·30배 성능 결과는 `docs/validated_experiments`의 별도 기록이며, 경로 통합 후 대규모 성능을 모두 다시 측정한 것은 아닙니다.
